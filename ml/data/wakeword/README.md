# Data wake word

- `positif/`: rekaman orang mengucapkan "Vine on" dan "Vine off". Rekam banyak orang dengan logat berbeda, termasuk lansia, karena "Vine" bisa terucap "Fain", "Vin", atau "Pain". Target minimal 20 orang × 5 rekaman per perintah.
- `negatif/`: rekaman obrolan biasa, suara TV, dan suara bangsal. Dipakai untuk menguji supaya Vine tidak salah aktif.

Format: WAV, 16 kHz, mono. Rekaman suara tidak masuk GitHub.
